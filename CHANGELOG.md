## 0.1.0 - 2026-10-15

### Added

- Convert the Gmail thread you are viewing into Markdown and copy it to the clipboard
- Copy from the `Markdownでコピー` (Copy as Markdown) button next to the print icon, `Alt+M`, or the userscript manager menu
- Read To, Cc, and Bcc from the "Show details" panel and list attachment names
- Remove reply quotes, tracking images, and hidden text, and convert tables and headings into Markdown
